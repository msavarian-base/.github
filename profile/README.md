## msavarian-base

Shared building blocks for every msavarian platform: the .NET framework, repository templates and
multi-tenant central services. Repositories here are not open for public contribution.

### Framework

- [dotnet-framework](https://github.com/msavarian-base/dotnet-framework) — **Sarv**, the shared .NET framework (DDD, CQRS, mediator, messaging, multi-tenancy, plugins), published to NuGet

### Templates

- [dotnet-template-modular-monolith](https://github.com/msavarian-base/dotnet-template-modular-monolith) — default starting point for a .NET service or platform backend
- [dotnet-template-clean-architecture](https://github.com/msavarian-base/dotnet-template-clean-architecture) — small .NET service with a single bounded context
- [angular-template](https://github.com/msavarian-base/angular-template) — Angular front end with localization, sign-in and feature flags

### Central services

- [dotnet-service-identity](https://github.com/msavarian-base/dotnet-service-identity) — central OAuth / OpenID Connect provider
- [dotnet-service-basedata](https://github.com/msavarian-base/dotnet-service-basedata) — shared reference data (provinces, cities, banks, holidays, …)
- [dotnet-service-workflow](https://github.com/msavarian-base/dotnet-service-workflow) — approval flows and state machines
- [dotnet-service-audit](https://github.com/msavarian-base/dotnet-service-audit) — central, tamper-resistant copy of audit logs
- [dotnet-service-billing](https://github.com/msavarian-base/dotnet-service-billing) — subscriptions, plans and invoices
- [dotnet-service-notification](https://github.com/msavarian-base/dotnet-service-notification) — SMS, email, in-app and push
- [dotnet-service-file](https://github.com/msavarian-base/dotnet-service-file) — file storage
- [dotnet-service-ticketing](https://github.com/msavarian-base/dotnet-service-ticketing) — ticketing
- [dotnet-service-url-shortener](https://github.com/msavarian-base/dotnet-service-url-shortener) — URL shortening
- [dotnet-service-wallet](https://github.com/msavarian-base/dotnet-service-wallet) — wallet and payments

### Shared workflows

- [.github](https://github.com/msavarian-base/.github) — reusable GitHub Actions workflows, issue forms and PR template

Maintained by [@msavarian](https://github.com/msavarian).
